Define qué sistema vas a analizar. Podrás importar su código después de crearlo.

Las credenciales se mantienen en el backend, no en el navegador.

Cada fase produce evidencia verificable y conserva el código original.

  1. Elige Codex, Claude o el motor Demo al crear el proyecto.
  2. Importa un ZIP o repositorio GitHub. El inventario se genera automáticamente.
  3. Ejecuta Understand, Assess y Plan en secuencia.
  4. Revisa y aprueba el plan; a continuación ejecuta Baseline.
  5. Modernize transforma una copia, no el repositorio original.
  6. Verify muestra las comprobaciones; revisa y aprueba o rechaza.

Los tests requieren VALIDATION_MODE=docker. En modo static no se declara equivalencia de comportamiento.
